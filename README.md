# 海智园区 · 企业信息查询原型

用于评审园区企业列表、企查查信息查询和企业详情展示的页面样式与交互。

预览地址：https://li13146730115-creator.github.io/haizhi-qcc-prototype/

## 当前范围

- 企业列表、企业搜索、园区及查询状态筛选。
- 单家企业查询、重新查询、失败重试及所选企业查询。
- 企业工商信息、专利技术（国内/国际专利、软件著作权）、融资信息、企业图谱、风险预警五组详情。
- 风险预警覆盖经营异常、严重违法、欠税公告、送达劳动仲裁四类核查结果。
- 嵌套数据、全部返回字段表格及 JSON 展示。

当前为样式原型，企业、人员、联系方式和查询结果均为虚构示例，尚未接入真实企查查服务。字段结构也为演示结构，不代表已经核对真实接口的完整返回字段。

本仓库仅包含原型的页面、样式、脚本和图标依赖，不包含原项目资料。

图标来自 Lucide，许可信息见 `vendor/LICENSE`。
